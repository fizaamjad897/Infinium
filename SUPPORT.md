# Support

For setup, read [README](README.md), [configuration](docs/configuration.md), and [testing](docs/testing.md). Search existing issues before opening a new one.

A useful issue includes the component, branch/commit, runtime versions, sanitized logs, exact steps, expected result, and actual result. Remove tokens, email contents, private repository paths, and personal data. Use a synthetic example whenever possible.

Security concerns: [private reporting](https://github.com/fizaamjd/Infinium/security/advisories/new). This is a portfolio/research project with no support SLA.
