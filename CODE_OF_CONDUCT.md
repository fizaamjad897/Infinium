# Code of conduct

Treat contributors and users respectfully. Welcome questions, give specific constructive feedback, and acknowledge other people's work. Harassment, discriminatory language, personal attacks, doxxing, and publishing private information are unacceptable in issues, pull requests, discussions, or other project spaces.

Maintainers may edit or remove harmful content, restrict participation, and close discussions that violate these expectations. They will consider context, protect reporter privacy where practical, and explain moderation decisions when doing so is safe.

For conduct concerns, use the maintainer's contact details listed on their GitHub profile. If none are available, open an issue requesting private contact without describing the incident or identifying anyone. Do not post sensitive reports publicly. A maintainer involved in a complaint should not decide its outcome alone. Participation means following these expectations; there is no guaranteed moderation response time.
